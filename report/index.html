一、代码重构：单主程序 → 两模块头文件架构

原始代码将所有功能集中在一个主程序中，代码耦合度高、可维护性差。重构后拆分为两个独立模块：encoding.h（编码解码）、data_io.h（数据读取），主程序仅负责调用。

文件结构

DFJSP_Project/ ‏ main.cpp # 主程序入口，调用两个头文件 ‏ encoding.h # 编码+解码模块（双编码表示 + 解码器） ‏ data_io.h # 数据读取模块（输入解析与参数配置） ‏ fga/ # 测试实例文件夹 ‏ fga1.txt ‏ ...

encoding.h — 编码+解码模块

该头文件封装了完整的双编码表示与解码调度算法：

// ============================================ // encoding.h — 编码+解码模块 // 双编码表示 + 7步解码调度 + 关键路径分析 // ============================================ // ----- 编码结构体 FoodSource ----- struct FoodSource { vector<int> OS; // Operation Sequence 工序排序 vector<int> MS; // Machine Sequence 机器分配 vector<int> AT; // Assembly Time 装配序列 vector<int> jobFactory; // 工厂分配 double fitness; int trial; }; // ----- 双编码表示 ----- // 三向量编码(解码专用): OS + MS + AT // 工厂-机器分配(算子专用): jobFactory + machineAssign // syncEncoding() 保持两种表示同步 void syncEncoding(FoodSource& fs); // ----- 解码器：七步调度生成 ----- // 1. 初始化机器可用时间表、AGV位置追踪 // 2. 遍历OS序列逐道调度 // 3. AGV运输调度（顺路接任务） // 4. 机器加工: max(AGV到达, 机器可用) // 5. 装配点运输 // 6. 产品装配（串行） // 7. 计算Makespan double decodeSchedule(const FoodSource& fs); // ----- 关键路径分析 ----- void analyzeCriticalPath();

二、创新算法：多群体ABC算法详解

基于多群体ABC（Artificial Bee Colony）的分布式柔性作业车间调度（DFJSP）算法，提出三异质蜂群协同进化架构，融合自适应算子选择与关键路径分析。

1. 数据输入

  • 读取数据文件 fga*.txt
  • 解析工件数 / 机器数 / 工厂划分
  • 读取加工时间、AGV运输时间、产品装配参数

2. 双编码表示 (Dual Representation)

编码类型用途说明
三向量编码解码专用OS(Operation Sequence) + MS(Machine Sequence) + AT(Assembly Time)
工厂-机器分配算子专用jobFactory[j] + machineAssign[j][o] → syncEncoding() 保持同步

3. 种群初始化 (60个食物源)

比例策略说明
70%随机生成完全随机分配工厂和机器 → Fisher-Yates洗牌OS序列
15%时间优先首工序选最短加工时间机器，后续优先同机
15%交错生成首工序选最短时间，后续优先选与下一工序共享的机器

4. 初始化三个异质蜂群

蜂群策略规模权重说明
蜂群ATIME_FIRST20[0.6, 0.2, 0.2]每工序选加工时间最短的机器
蜂群BLOAD_BALANCE20[0.2, 0.6, 0.2]识别瓶颈机器，转移工序到低负载机器
蜂群CAGV_SMOOTH20[0.2, 0.2, 0.6]相邻工序尽量同机器，减少AGV运输

5. 主循环 while(elapsed < stopMs)

5.1 雇佣蜂阶段 — 各蜂群邻域搜索

  • 蜂群A neighborShortestMachine
  • 蜂群B neighborLoadBalancing
  • 蜂群C neighborSameMachine

5.2 观察蜂阶段 — epsilon-贪婪选择异质算子

算子策略说明
O1BottleneckReassign瓶颈工厂重分配
O2RandomPerturb随机扰动重分配
O3HighFitnessCrossover高适应度OS交叉

权重自适应：成功 +0.03 / 失败 -0.02 → 归一化 → epsilon-贪婪 = 0.4 随机探索，0.6 权重搜索

5.3 侦察蜂阶段 — 自适应LIMIT

  • trial > LIMIT 放弃旧解，生成新解
  • LIMIT 范围 [10, 50]，根据蜂群贡献度动态增减

5.4 迁移阶段 (每30代)

  • 贡献度 = 1 / bestMakespan
  • 各蜂群交换最优个体，仅当改进 ≤ 5% 阈值时接受
  • 动态规模调整：贡献度低的迁出，贡献度高的迁入，最小规模 6

6. 解码器：七步调度生成

步骤操作
6.1初始化机器可用时间表、AGV位置追踪
6.2遍历OS序列：按工序序列逐道调度
6.3AGV运输调度：计算工序间搬运时间，AGV可顺路接同厂下一任务
6.4机器加工：工序开始时间 = max(AGV到达时间, 机器可用时间)
6.5装配点运输：最后工序完成后，装配AGV将工件运至装配点
6.6产品装配：同产品所有工件到齐后串行装配
6.7计算Makespan：所有产品装配完成的最晚时间

7. 关键路径分析

  1. 记录前驱关系：同工件前一工序 + 同机器前一工序
  2. 逆向回溯：从最晚完工产品的最后工序开始，选结束时间更晚的前驱
  3. 标记关键元素：被回溯路径上的工序/工件/机器被标记为"关键"
  4. 输出瓶颈信息：bottleneckMachine / maxMachineLoad / criticalOps
